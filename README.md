# VolunteerLink – Trang Quản lý người dùng (Admin)

- **Tên đề tài:** VolunteerLink – nền tảng kết nối tình nguyện viên và tổ chức xã hội
- **Trang đã thực hiện:** Quản lý người dùng (vai trò Quản trị viên)

## Mục đích của trang
Giúp quản trị viên xem danh sách tài khoản, tìm kiếm/lọc, phê duyệt tài khoản mới, khóa/mở khóa, tạo và sửa người dùng.

## Các chức năng chính
- Tìm kiếm theo tên hoặc email (sự kiện `input`)
- Lọc theo vai trò và trạng thái (sự kiện `change`)
- Phê duyệt tài khoản "Chờ duyệt"
- Khóa / Mở khóa tài khoản (đổi trạng thái)
- Tạo mới / Sửa người dùng bằng modal, có kiểm tra form (validation)
- Đặt lại mật khẩu (mô phỏng bằng thông báo)
- Responsive: sidebar thành menu ngang, bảng cuộn ngang trên mobile

## Công nghệ sử dụng
HTML5 (semantic), CSS3 (Flexbox, Media Query), JavaScript thuần (DOM, Array, Event)
